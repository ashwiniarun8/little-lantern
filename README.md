# Little Lantern — A Small Cooking World

A cozy, illustrated cooking-world website . Rather than a conventional restaurant page, Little Lantern is organised as a collection of little places to explore.

## What's inside
- **Ramen Shop:** browse a few broth and noodle ideas.
- **Kitchen:** open recipes with ingredients, preparation time and step-by-step instructions.
- **Pantry:** add ingredients, mark what's available and check what's needed.
- **Noticeboard:** tick off small cooking challenges and track progress.
- **Recipe Wall:** open cooking-video searches and pin your own video links.
- **Chicken Corner:** a small set of chicken recipe ideas.
- Responsive navigation and layouts for desktop and mobile.

## Technology
- HTML
- CSS
- Vanilla JavaScript

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser.
3. No package installation or build step is required.

## Files
- `index.html` — page structure and content
- `style.css` — hand-painted, paper-and-wood inspired design and responsive layout
- `script.js` — menu selection, recipe dialogs, pantry list, saved recipes, video links and challenge progress

## Storage note
Pantry items, saved recipes, pinned video links and challenge progress are saved in the current browser using `localStorage`. They are not shared between different devices or users. The example video links open YouTube search results rather than a fixed video.
